📊 Campaign Tracker
🧩 Project Overview

The Campaign Tracker is a web-based application developed to help users manage, monitor, and analyze multiple campaigns in one place.
It provides an intuitive and responsive interface where users can record campaign details, track performance, and visualize progress using simple charts and summaries.
This project was created as part of the Ginger Media Technical Role Assignment.

🎯 Project Purpose

The main goal of this project is to demonstrate front-end web development, data management, and visualization skills using core web technologies.
It showcases the ability to build an interactive, user-friendly, and responsive interface that delivers meaningful insights through data-driven components.
By implementing this project, it reflects both technical proficiency and practical problem-solving in developing modern web applications.

🚀 Features

✅ Add, edit, and delete campaign entries easily

📅 Track and monitor campaign progress over time

📊 Display visual insights using charts and graphs

💾 Dynamic data handling for performance tracking

🌐 Fully responsive design suitable for all devices

🎨 Simple, clean, and modern UI using HTML, CSS, and JavaScript

🧱 Technologies Used

Frontend: HTML5, CSS3, JavaScript

Visualization: Chart.js (if used for graphs)

Hosting: GitHub Pages / Netlify

⚙️ How to Run Locally

Download or Clone the Repository

git clone https://github.com/SharanyaBS-10/Campaign-Tracker.git


Extract Files (if downloaded as ZIP)

Open the project folder and double-click index.html to view it in your browser.

The application will open and display the campaign tracking interface.

🌍 Hosting Instructions (for Submission)

To make this project live and accessible:

Upload all files to your GitHub repository.

Navigate to Settings → Pages.

Under Source, select:

Branch: main

Folder: / (root)
Then click Save.

After 1–2 minutes, your hosted site will be available at:

https://<your-username>.github.io/Campaign-Tracker/


Share this link for your assignment submission.
